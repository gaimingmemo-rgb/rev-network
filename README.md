## ⚔️ Aesthetic & Architecture

Rev Network is engineered from the ground up to unite **high-octane defensive cybersecurity**, **low resource footprint**, and **seamless decentralized community sharing**:

- **Obsidian & Sith Crimson Chassis**: Carbon-steel background palette (`#08090c`, `#10131a`) with glowing crimson cyber-accents (`#ff1e38`).
- **Tactical Navigation Core**: Integrated fast search engine switcher (Google, DuckDuckGo, Brave, Bing, Startpage), live RAM purge button, shield telemetry dialog, and downloads vault.

- **P2P Node Telemetry Bay**: Real-time hardware telemetry disclosing node CPU, RAM buffer allocation (~16 MB), and mesh synchronization throughput.

## 🛡️ Core Capabilities & Defensive Arsenal

### 1. 🛡️ Built-in Ad & Tracker Vaporizer (`adblocker.py` + `interceptor.py`)
- **C++ Network Interception**: Drops advertising, tracking pixels, analytics beacons, and cryptominers at the socket layer before bytes transfer.
- **Dynamic Cosmetic Cleaning**: Injects dynamic CSS rules into document DOMs to collapse and eradicate empty ad banners and sponsor slots.
- **Tactical Stream Skipper**: Auto-advances and auto-skips pre-roll and mid-roll stream advertisements.

### 2. ⚡ Ultra-Low RAM Architecture (`ram_optimizer.py`)
- **Intelligent Tab Hibernation**: Automatically suspends idle tabs after 5 minutes of inactivity while preserving URL state and history.
- **Windows Kernel Working Set Trim**: Invokes Win32 `EmptyWorkingSet` across all parent and child QtWebEngine renderer processes.
- **Strict Process Caps**: Limits renderer sub-processes and throttles background timers.

### 3. ☣️ Integrated Virus Scanner & Threat Interceptor (`virus_scanner.py`)
- **Heuristic Threat Inspection**: Pre-download safety barrier on hazardous extensions (`.exe`, `.scr`, `.bat`, `.cmd`, `.vbs`, `.ps1`).
- **Streaming SHA-256 Engine**: Computes cryptographic hashes in real-time as bytes stream to disk.
- **Windows Defender Engine Bridge**: Directly commands Microsoft Defender's native engine (`MpCmdRun.exe`) to scan incoming payloads.
- **Quarantine Vault**: Automatically isolates infected or untrusted downloads in `data/quarantine/`.

### 4. 🌐 Rev Community Hardware Node (`assets/community.html`)
- Accessible via the **`[ 🌐 REV COMMUNITY ]`** button or `imperial://community`.
- Live hardware telemetry disclosing local CPU, RAM, and network relay bandwidth.
- Community Pilot Registry, live SWG server fleet browser, and direct installer distribution bay.

## 🚀 Quick Start & Installation

### Requirements
- **OS**: Windows 10 / Windows 11 (64-bit)
- **Python**: 3.10+ (tested through 3.14)
- **Dependencies**:
  ```bash
  pip install -r requirements.txt
  ```

### Run from Source
```powershell
# Clone the repository
git clone https://github.com/gaimingmemo-rgb/rev-network.git
cd rev-network

# Install requirements
pip install -r requirements.txt

# Launch Rev Network
python main.py
# or double-click run.bat
```

### Build Standalone Executable (.exe)
```powershell
# Compile Rev Network into a standalone portable bundle
pyinstaller RevNetwork.spec

# Compile the Tactical Setup Installer
pyinstaller Rev-Network-Setup.spec
```
